PERHITUNGAN MANUAL SPL 3 VARIABEL DENGAN ELIMINASI GAUSS

Diketahui:
2x + y - z = 8
-3x - y + 2z = -11
-2x + y + 2z = -3

1. Membentuk matriks augmented

[  2   1  -1 |   8 ]
[ -3  -1   2 | -11 ]
[ -2   1   2 |  -3 ]

2. Eliminasi kolom pertama

Gunakan baris pertama sebagai pivot. Operasi:
R2 <- R2 + (3/2)R1
R3 <- R3 + R1

Hasil:
[ 2   1   -1 |  8 ]
[ 0  1/2  1/2 |  1 ]
[ 0   2    1  |  5 ]

3. Eliminasi kolom kedua

Operasi:
R3 <- R3 - 4R2

Hasil:
[ 2   1   -1 |  8 ]
[ 0  1/2  1/2 |  1 ]
[ 0   0   -1  |  1 ]

Matriks sudah berbentuk segitiga atas.

4. Substitusi mundur

Dari baris ketiga:
-z = 1
z = -1

Dari baris kedua:
(1/2)y + (1/2)z = 1
(1/2)y + (1/2)(-1) = 1
(1/2)y = 3/2
y = 3

Dari baris pertama:
2x + y - z = 8
2x + 3 - (-1) = 8
2x + 4 = 8
2x = 4
x = 2

5. Hasil akhir

x = 2
y = 3
z = -1

6. Pemeriksaan ke persamaan awal

Persamaan 1: 2(2) + 3 - (-1) = 8
Persamaan 2: -3(2) - 3 + 2(-1) = -11
Persamaan 3: -2(2) + 3 + 2(-1) = -3

Ketiga persamaan terpenuhi. Jadi solusi SPL adalah (x, y, z) = (2, 3, -1).
